\section{A Question With Parts \points{12}}

A section is the unit of a question: a heavy bar, then the numeral set large
in the margin with the title flush beside it and the point value in a block at
the right. Question text follows as ordinary prose.

\marginlabel{Marginal notes live out here. Use them for hints, point splits,
or a pointer to the slide the question came from.}

\subsection{The first part}

Sub-parts take the same treatment one size down, with the numeral still
hanging in the margin.

\subsection{The second part}

Enumerated lists carry the house numeral, reversed out of a solid square:

\begin{enumerate}
    \item State the invariant.
    \item Show it holds initially.
        \begin{enumerate}
            \item The base case.
            \item The step.
        \end{enumerate}
    \item Conclude.
\end{enumerate}

\section{A Question Without Parts \points{8}}

Some questions are a single paragraph and a demand. Those need no structure,
just the heading and the ask.

\begin{asidebox}{Hint}
    Start from the definition, not from the result you want.
\end{asidebox}
