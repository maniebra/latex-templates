and there should not be any in yours — a tinted header row and generous row
padding separate columns perfectly well.

\begin{note}[Column specs]
\texttt{X} is the stretchy column — give it the prose and let the rest size to
content. \texttt{colspec = \{lXr\}} covers most tables you will ever write.
\end{note}

\section{Lists}

Bullets take the accent colour at level one and fade at deeper levels:

\begin{itemize}
  \item A first-level item, in the accent colour.
  \begin{itemize}
    \item Second level, hollow and muted.
    \begin{itemize}
      \item Third level, a plain dash.
    \end{itemize}
  \end{itemize}
  \item Spacing is tightened from LaTeX's defaults, which are set for
        double-spaced manuscripts nobody prints any more.
\end{itemize}

Numbered lists get a semibold accent numeral:

\begin{enumerate}
  \item Edit \texttt{vars/colors.tex} and \texttt{vars/meta.tex}.
  \item Write in \texttt{sections/}.
  \item Add each file to \texttt{main.tex}.
  \item Run \cmd{latexmk -lualatex -shell-escape main.tex}.
\end{enumerate}
